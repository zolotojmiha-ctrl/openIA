# АРМАДА 6.17.1 — исправления по результатам проверки ЛК

Полный пакет поверх 6.17.0; включает предыдущие изменения. Новых миграций относительно 6.17.0 нет.

## Что исправлено

- В ведомости участка есть явная кнопка «↓ Скачать Excel». Выгрузка учитывает участок, контракт и выбранные фильтры, включая доработку и старые записи. До 10 000 работ без молчаливого обрезания; при превышении требуется сузить выборку.
- «Выполнение работ» содержит «Все работы и дефекты». В общем списке видны фильтры контракта, участка и ведомости нефтепровода. Руководителю доступны кнопки проверки ежедневных работ и согласования указаний.
- Переходы к удалённым, восстановлению и обратно сохраняют контекст и поиск. Импорт из участка закрепляет контракт и участок; после сохранения возвращает в исходный участок.
- При подготовке дефектов нефтепровод подставляется, но остаётся доступным для изменения: ОИ и УБО не смешиваются. РНУ наследуется из контекста.
- Убраны доступные только по адресу входы в проверенные рабочие разделы. Кнопка загрузки комплектов не показывается пользователю без права загрузки. Импорт участков показывает результат среди участков без контракта.
- Исправлены подписи и параметры ссылок в навигации документов.

## Проверка

573 основных теста PostgreSQL 17 и 22 сценария Chromium прошли успешно. После финального уточнения фильтров дополнительно прошли 72 проверки PostgreSQL и три проверки браузера/выгрузки. Проверена навигация четырёх ролей от главной страницы через видимые ссылки. Подробный отчёт: CABINET_AUDIT_2026_10_28.md.

Проверки проводились на синтетических данных. Реальная доставляемость почты и API Beget на боевой учётной записи не подтверждались. Ранее показанная ошибка с пределом сообщения 4 МБ не воспроизведена.

## Установка

В существующей папке выполнить резервное копирование `bash deploy/beget/backup.sh`, распаковать пакет поверх неё, затем:

```sh
docker compose -f deploy/beget/compose.yml build web
docker compose -f deploy/beget/compose.yml up -d
docker compose -f deploy/beget/compose.yml ps
```

Сохранить deploy/beget/.env и все постоянные тома. Повторно создавать пользователей не нужно. После установки обновить страницу: ⌘ShiftR. Версия в шапке — 6.17.1.
