# Проверка первого этапа 6.1.0-foundation

Дата: 22 октября 2026. Проверка выполнена в облачной среде на синтетических данных.
NAS и пользовательская рабочая база не использовались.

- Общая регрессия: **242 теста, OK, 6 пропусков**. Включены accounts, projects,
  documents, repairs и finance, старые браузерные сценарии и новый путь техника.
  Шесть пропусков — проверки блокировок PostgreSQL при запуске на SQLite.
- Изолированный PostgreSQL 17: **226 тестов, OK, без пропусков**. Включены
  права, миграция старой схемы, контрактная изоляция, создание/связь аккаунта,
  ручное распределение старых работ и конкурентное назначение одного задания
  двум контрактам. Временные контейнер и сеть удалены после проверки.
- Браузер: вход техника → контракт/место/участок → создание работника → аккаунт →
  выдача объектного и контрактного доступа → создание задания с выбранным мастером →
  распределение старого задания → смешанный контракт арматура/диагностика → телефон 390 px.
- Сохранены браузерные проверки документов, финансовой карточки, договоров и полей,
  черновиков с фото без сети, повторной отправки, проверки руководителем,
  Excel и смены мастера. Исправлен конфликт запоздавших ответов подбора мастера.
- Excel: выгрузка содержит ID контракта; импорт в другой контракт отклоняется.
- Миграция 6.0.7 → 6.1.0 сохраняет ID, точность старого километра, ведущие нули,
  автора результата, хеш/ключ вложения, приёмку, версии сеансов и прежние права.
  Контракт и вид работ автоматически не выбираются.
- Django check, makemigrations --check --dry-run, git diff --check — без ошибок.
- Docker Compose проходит проверку конфигурации. Образ Python 3.12 собран из
  прежних 13 wheels с проверкой хешей; новых зависимостей нет.

## Что эта проверка не утверждает

Это проверка первого этапа, а не готовность всех 63 требований из сверки.
Другие производственные модули, полный новый мобильный список, бригады,
массовое подтверждение/возврат, техника, склады, субподрядчики, общий Excel,
сроки документов, расширенный офлайн и процедура закрытия остаются в плане.
Их отсутствие в этом этапе явно описано в FOUNDATION_6_1.md.

Не выполнены установка на NAS и сверка с фактической рабочей базой.
