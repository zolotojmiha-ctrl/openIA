# 6.33.8 — рабочий доступ сотрудника и меню ПТО в MAX

- В разделе «Персонал» через «Выдать доступ» или «Настроить доступ» руководитель задаёт должность и назначает рабочий доступ за одно сохранение.
- Для ПТО назначение действует на весь контракт, включая добавленные позднее участки. Для остальных внутренних сотрудников участки можно выбрать в той же форме.
- В MAX ПТО получает рабочие разделы и уведомления в пределах своих прав. Сводки техники и аренды доступны руководителям.
- Установка поддерживает переход с 6.33.7 и повторный запуск. Миграции базы не требуются. Установщик создаёт зашифрованную резервную копию и сохраняет настройки.

Каталог recovery содержит прежнюю версию приложения и закрытые настройки. Сохраняйте последний завершённый комплект и незавершённые комплекты. Старые завершённые комплекты можно удалить вручную после проверки восстановления соответствующей копии. Для просмотра списка используйте `python3 deploy/beget/recovery_inventory.py --directory /opt`.
