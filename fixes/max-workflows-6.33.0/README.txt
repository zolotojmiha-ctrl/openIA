Накопительное исправление интерфейса работ MAX поверх 6.33.0.

После установки отправьте /меню заново.
«Раскладки секций» — загрузка и выбор справочника XLSX; это отдельная административная функция.
«Расстояния» — участок → работа → расстояния между началами секций.
«Работы и дефекты» руководителя/ПТО — участок → текущие работы по возрастанию км → карточка в боте с доступными действиями. Устранённые отдельно. В «Моих работах» мастера также порядок по км; прежнее внесение результатов сохранено.
«Метод после ДДК» — сначала участок, затем разрешённые работы по км. Сам ввод/вложения/подтверждение внутри бота как прежде.
«Фото хода работ» руководителя — отдельно «Добавить фотографии» и «Полученные фотоотчёты». Добавление: участок → работа → фотографии → сохранение в самом боте. Дата по умолчанию сегодняшняя; этапы и подпись необязательны. Это не завершение ремонта и не списание материалов.
В полученных ежедневных фотоотчётах бот показывает даты, количество и подписи; оригиналы открываются по прежней защищённой ссылке ЛК. Отправка приватных оригиналов непосредственно в MAX новым механизмом не добавлялась. Итоговые фото ремонта автоматически не смешиваются с ежедневными фотоотчётами.
Списки: короткие однострочные км/№/метод, страницы и возврат, без дублей общего ремонта. Новосибирское РНУ → НСК, Омское РНУ → Омск только на кнопках; названия в базе сохраняются.

Достаточно установить этот пакет: прежние исправления расстояний и коротких РНУ уже включены. Версия кабинета остаётся 6.33.0. Архив, раскладки, часы, остатки, права и привязки сохраняются; заново импортировать данные не требуется. Модели/миграции/зависимости/установщик не менялись. Автоматизация подготовки пустой ведомости нового участка в этот пакет не входит.

После проверки подписи внешнего ZIP сохранённым доверенным ключом и распаковки в /root:
ARMADA_APP_ROOT=/opt/armada ARMADA_RELEASE_PUBLIC_KEY=/root/armada-6.32.0/armada-release-signing.public.pem bash /root/armada-max-workflows-fix/install-6.33.0.sh
