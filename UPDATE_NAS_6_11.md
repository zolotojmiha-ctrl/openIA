# Обновление 6.11.0 через Container Manager

Архив содержит папку openIA-feature-accounts-foundation — как в действующем пути проекта:
/volume1/docker/armada-test/openIA-feature-accounts-foundation

Сохраните резервную копию БД, документов и конфигурации. Используйте тот же проект armada-test, путь и подключения существующих томов. Не удаляйте тома и не создавайте новый проект вместо прежнего.

После остановки проекта замените исходники файлами из архива. В поставляемом docker-compose.yml web и init используют armada-test-web:customer-changes-v6.11.0. Если используете свой YAML, сохраните его сеть/тома/настройки, обновив только образ и код сборки. Пересоберите и запустите проект через Container Manager. Миграции выполняются при старте web; дождитесь исправного состояния db/web. Код предыдущих этапов включён.

После запуска версия в кабинете — 6.11.0-customer-changes. Реестр доступен через «Договоры» → карточка → «Указания заказчика и изменения», а также из рабочего раздела контракта. Руководителю доступна очередь на главной. Детали: CUSTOMER_CHANGES_6_11.md.

В пакет не включены база, документы и секреты облачной среды. Зависимости Python включены для сборки Linux amd64; при отсутствии базовых Docker-образов потребуется их загрузка. Публичный доступ и конфигурация NAS разработчиком не менялись. Этот выпуск не заменяет ежедневные ведомости диагностики/изоляции — их реализация следует за реестром согласований.
