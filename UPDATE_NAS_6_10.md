# Общий пакет 6.10.0 — обновление существующего проекта Container Manager

В архиве рабочий код всех подготовленных этапов 6.1–6.10: структура контрактов и объектов, бригады, проверки результатов, техника, склады, субподрядчики, закрытие контрактов, документы со страницами и сроками, главные экраны по должностям, черновики мастера, Excel. Это серверное приложение; каталог prototype не является рабочим кабинетом.

## Обновление

1. Сохраните резервную копию существующей базы, документов и конфигурации проекта штатным способом вашей установки. Экспорт одного контейнера не является копией Docker-томов. Миграции сохраняют данные, но для возврата к старой версии после изменения схемы нужна резервная копия.
2. В Container Manager остановите существующий проект. Не удаляйте проект с данными и не выбирайте очистку томов. Сохраните его имя, текущий путь и YAML.
3. Распакуйте архив отдельно и перенесите исходники поверх файлов в прежней папке проекта. Корнем проекта остаётся папка с docker-compose.yml. Не переносите исходники в новый одноимённый подкаталог вместо прежнего корня. Если YAML или настройки сети были изменены у вас, сохраните эти настройки и прежние подключения томов.
4. В YAML старого проекта обновите образ web и init на armada-test-web:registry-excel-v6.10.0 и сохраните сборку из deploy/synology/Dockerfile. В поставляемом docker-compose.yml это уже сделано. Имена и подключения томов database/config/documents не менялись. Не создавайте новый проект с другим именем: у него будут другие тома.
5. Через меню проекта выполните сборку/пересборку образа и запуск. Пакеты Python включены в deploy/synology/wheels, устанавливаются без обращения к PyPI. При отсутствии базовых образов Docker потребуется их загрузка. Пакет рассчитан на существующую установку Linux amd64 с PostgreSQL 17; он не выполняет смену версии базы.
6. Дождитесь завершения init с кодом 0 и исправного состояния db/web. При старте web автоматически выполняются недостающие миграции. На входе должна отображаться версия 6.10.0-registry-excel. Кабинет: http://192.168.50.248:18080/cabinet/ (если адрес и порт вашей установки не менялись).

Учётные записи, документы, права и история берутся из прежних томов. Начальная настройка руководителей повторно не требуется. Если старый контракт ещё не имеет вида работ, выберите его в карточке. Старые задания без привязки к контракту сохраняются; уполномоченный сотрудник распределяет их через раздел работ, автоматическое угадывание контракта не выполняется. В пакет не входят пароли, конфигурационные секреты, база и документы облачной среды. Фактическое обновление NAS разработчиком не выполнялось.

Проверьте после запуска вход прежней учётной записью, доступ к существующему объекту и документу, затем выгрузку Excel. Новые функции и их ограничения описаны в тематических MD-файлах. Полный автономный вход без сети не заявляется: черновик работает в открытой форме, а повторное открытие и отправка требуют связи.
