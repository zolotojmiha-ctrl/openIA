# Установка 6.32.0: абсолютный путь к установщику

12 ноября 2026. Подписанный пакет 6.32.0 неизменен. Установщик переходит в каталог приложения и проверяет собственную подпись; при относительном вызове `bash install-6.32.0.sh` он ищет свой файл уже в каталоге приложения. Ошибка FileNotFoundError на этой проверке происходит до сборки и остановки служб.

Из распакованного пакета на текущем VPS выполнять:

```bash
ARMADA_APP_ROOT=/opt/armada \
ARMADA_RELEASE_PUBLIC_KEY=/root/armada-6.32.0/armada-release-signing.public.pem \
bash /root/armada-6.32.0/install-6.32.0.sh
```

Скачивать или править установщик заново не требуется. Шаблон исправлен для следующего выпуска: абсолютный script_path сохраняется до смены каталога. Изолированные проверки выпущенного пакета выполнялись с абсолютным путём; добавлены регрессионные тесты относительного вызова. Это исправление исходника не меняет байты, подписи и контрольные суммы опубликованного 6.32.0. Итог производственного обновления определяется последующим выводом установщика и проверкой служб, а не наличием этой инструкции.
