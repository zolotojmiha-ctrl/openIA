# АРМАДА 6.20.1

[Скачать обновление](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.20.1-update.zip)

Пункт меню Склады открывает общий список материалов со складом в каждой строке. Видимая кнопка Изменить: количество, характеристики и перемещение. Для старой карточки без остатка — Указать склад и количество без создания дубля. Настройка складов — отдельное дополнительное действие. Подробности RELEASE_6_20_1.md в архиве.

Перед установкой выполнить deploy/beget/backup.sh. Сохранить .env, базу, документы и ключи. Пользователей повторно не создавать.

Проверено: 170 целевых тестов PostgreSQL и 5 браузерных сценариев склада; переход с 6.20.0 и резервное копирование/восстановление.
