# АРМАДА 6.23.0

[Скачать обновление](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.23.0-update.zip) · [Скрипт установки](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/install-6.23.0.sh)

Работающие публичные анкеты и запросы: сохранение в закрытом кабинете «Почта → Заявки с сайта», письмо на info@armada-sibir.ru с исходным резюме. Удалены пометки о согласовании. Доставка использует подключённый info; при отсутствии реквизитов обращения остаются в кабинете и очереди. Включены заметные складские действия и прямое добавление участков.

Обновление поверх 6.22.2 с миграцией новых таблиц. Установщик проверяет SHA256, собирает новый образ до замены файлов, затем создаёт резервную копию, обновляет приложение и прокси, проверяет запуск. Сохраняются .env, база, документы и ключи. Пользователей повторно не создавать.

Проверено: 875 тестов PostgreSQL, сценарии четырёх форм в браузере и локальная доставка SMTP/TLS, изолированный переход с 6.22.2, создание резервной копии и её фактическое восстановление. Готовый ZIP сверяется побайтно с исходным коммитом. Реальная доставка в корпоративный info проверяется после установки; производственная база в тестах не использовалась.

Подробности: RELEASE_6_23.md и RELEASE_6_23_VALIDATION.md в архиве.

Исходный коммит: 5ebfdf1c7e44fb85f45a9b08c3fc2598506aec09
