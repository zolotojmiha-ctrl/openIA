# АРМАДА 6.16.0

[Скачать обновление](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.16.0-update.zip)

Полный пакет согласованных рабочих доработок: кабинет заказчика с публикацией, комплекты допуска и ZIP с историей версий, независимое закрепление техники и водителей, назначения людей и бригад из участка, действия с документами и удаление пустых участков, понятные наборы прав, прямая корректировка дефектов, подключаемое создание почты в Beget, документы до 32 МБ, robots/sitemap публичного сайта. Подробности и проверки RELEASE_6_16.md.

Перед установкой выполнить deploy/beget/backup.sh. Не удалять тома и не создавать руководителей повторно. После обновления пересоздать proxy для нового предела загрузки. Папка архива openIA-feature-accounts-foundation.

Автоматизация Beget выключена по умолчанию; реквизиты API вводит руководитель в ЛК. Живое API владельца не вызывалось в тестах. Заказчикам нужно отдельно назначить участки и опубликовать сведения.

Проверено: 542 теста PostgreSQL, четыре браузерных сценария, переход с 6.15.0, резервная копия и восстановление, Caddy validate.
