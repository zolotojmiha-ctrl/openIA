# АРМАДА — обновление 6.24.1

Часы аренды в карточке техники, потребность в складах, расход в карточке ремонта. Дополнительные пункты главного меню убраны. После обследования можно изменить требуемую конструкцию с сохранением причины и истории; неподходящее закрепление снимается без списания изделия.

Исходники: [неизменяемый коммит d6fb4a538d49](https://github.com/zolotojmiha-ctrl/openIA/tree/d6fb4a538d49190736e81a42eb2c8299e88501fb).

## Файлы

- [Архив 6.24.1](openIA-6.24.1-update.zip)
- [Установщик Beget](install-6.24.1.sh)
- [Контрольные суммы](openIA-6.24.1-update.sha256)
- [Метаданные и проверки](openIA-6.24.1-update.json)

Установщик рассчитан на существующую установку в /opt/armada/openIA-feature-accounts-foundation. Проверяет SHA-256/ZIP, собирает образ до замены файлов, создаёт резервную копию базы, документов, настроек и ключей. Данные и тома не сбрасываются. Переход с 6.24.0 и фактическое восстановление проверены на изолированной синтетической установке. Разработчик производственный сервер не обновлял.

После установки обновите страницу кабинета. Часы: «Техника → нужная машина». Потребность: «Склады → Потребность на работы». Изменение задания: карточка ремонта → «Что требуется → Уточнить конструкцию после обследования». Для уже смонтированной конструкции используется исправление результата.

Полный прогон PostgreSQL: 925 тестов, OK; после последних уточнений — 43 профильных проверки, включая Chromium и конкурентные операции. Старые пакеты сохранены. Ограничения нормирования изоляции и отложенных электродов выпуска 6.24.0 остаются.
