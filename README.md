# АРМАДА — обновление 6.25.1

Полный складской доступ ПТО, Excel потребности и обеспеченности муфтами, одна кнопка прикрепления файлов договора, понятный указатель текущего складского раздела. Новых главных пунктов меню нет.

Исходники: [неизменяемый коммит 8daa049eec00](https://github.com/zolotojmiha-ctrl/openIA/tree/8daa049eec00c469c914d80a3081169618a0a063).

## Файлы

- [Архив 6.25.1](openIA-6.25.1-update.zip)
- [Установщик Beget](install-6.25.1.sh)
- [Контрольные суммы](openIA-6.25.1-update.sha256)
- [Метаданные и проверки](openIA-6.25.1-update.json)

Установщик рассчитан на существующую установку в /opt/armada/openIA-feature-accounts-foundation. Проверяет SHA-256/ZIP, собирает образ до замены файлов, создаёт резервную копию базы, документов, настроек и ключей. Данные и тома не сбрасываются. Переход с 6.25.0 и фактическое восстановление проверены на изолированной синтетической установке. Разработчик производственный сервер не обновлял.

Существующим сотрудникам с ролью «Инженер ПТО» добавляется отсутствующее складское право; для новых сотрудников оно входит в набор ПТО. Финансовые права не добавляются. Прежние индивидуальные права и ограничения контрактов/участков сохраняются.

В «Потребности на работы» Excel содержит итог, детализацию по работам, сведения для уточнения и отдельный фактический расход. В «Хватит ли муфт на работы?» Excel повторяет таблицу и выбранные фильтры. Количества — числовые ячейки. Неполные сведения не подменяются нулями. Расчёт и выгрузка не списывают складской запас.

После установки обновите страницу кабинета. Правила П1/П2, фактический монтаж, деньги, тарифы, часы, закрытые периоды и остальные данные сохраняются. Отсутствующие нормы и отложенные электроды не объявляются реализованными.

Полный PostgreSQL: 963 тестов, OK. Заключительный профиль: 13 тестов, OK, включая настоящий Chromium и конкурентные операции. Старые пакеты сохранены.
