# Обновление АРМАДА 6.13

[Скачать архив](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.13.0-update.zip)

Внутри папка **openIA-feature-accounts-foundation**. Исходники, миграции, зависимости, обновление NAS и отдельная сборка для Beget включены. Перенос сохраняет существующие данные и учётные записи; удалять тома не нужно.

Почта внутри ЛК: папки, чтение, ответ, пересылка, вложения, черновики и очередь отправки. Сотрудник видит свои ящики, оба руководителя — все подключённые. При создании сотрудника можно запросить почту; настоящий ящик пока создаётся вручную в панели Beget и затем подключается в ЛК. Автоматическое создание через API провайдера не реализовано.

Журналы выполнения по диагностике, замене изоляции, арматуре и строительству; подтверждение/возврат, история редакций, массовая проверка и Excel. Сохранены прежние исправления, роли, простые пароли и изменение ФИО.

Проверки: 498 серверных тестов PostgreSQL, 16 браузерных сценариев, локальные TLS IMAP/SMTP и восстановление резервной копии. Реальная почта Beget и публичное развёртывание ещё требуют настройки на сервере.

Инструкции в архиве: RELEASE_6_13.md, VERIFICATION_6_13.md, UPDATE_NAS_6_13.md, deploy/beget/README.md. NAS/VPS и DNS разработчиком не менялись. Прочие границы реализации перечислены в RELEASE_6_13.md.
