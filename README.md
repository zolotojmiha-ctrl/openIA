# Обновление АРМАДА 6.14.1

[Скачать архив](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.14.1-update.zip)

Исправлен порядок: сначала создаётся контракт заказчика без объектов, затем из его карточки добавляются новые объекты или выбираются существующие. Создание объекта из карточки автоматически привязывает его к выбранному контракту. Excel тоже допускает контракт без объектов. Уполномоченный редактор сохраняет явный доступ к своему контракту, не получая доступа к чужим.

Все функции 6.14 включены, данные не обнуляются. Убрана учебная надпись о вымышленных данных с рабочих форм. Инструкция и проверки: FIX_CONTRACT_FIRST_6_14_1.md. Перед установкой создайте резервную копию; повторно создавать руководителей и удалять тома не нужно.

Проверки: 512 тестов PostgreSQL, браузерный путь «контракт → объект» с пустой установки и прежний сценарий техника, переход с 6.14.0, резервное копирование и восстановление.

Папка в архиве: **openIA-feature-accounts-foundation**. Настоящий VPS разработчиком не обновлялся; установка выполняется пользователем. Автоматическое создание почтовых ящиков у провайдера по-прежнему не подключено.
