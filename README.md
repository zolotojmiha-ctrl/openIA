# Обновление АРМАДА 6.14

[Скачать архив](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.14.0-update.zip)

Внутри прежняя папка **openIA-feature-accounts-foundation**. Для существующего Beget: UPDATE_BEGET_6_14.md. Перед заменой исходников создайте резервную копию. Не очищайте базу и тома, не создавайте руководителей повторно.

Отдельный реестр договоров с контрагентами: субподряд, аренда техники и жилья, поставки, ссылки на существующие контракт заказчика/объект/технику, файлы, Excel, архив и история. Старые контракты остаются в «Контракты с заказчиками», рабочий раздел называется «Выполнение работ».

Понятные формы работников без учётной записи и доступа в ЛК; подсказка мастеру; компактные документы техники со сроками и статусами; счётчики у каждого почтового ящика; цвет и подпись непрочитанных; обновление статуса чтения; меньше почтовых уведомлений; иконка Safari со знаком компании. Исправление общего ящика без сотрудника включено.

Проверки: 508 серверных тестов PostgreSQL, браузерные сценарии, переход 6.13 → 6.14 с сохранением данных и восстановление резервной копии. Подробности: RELEASE_6_14.md, VERIFICATION_6_14.md.

Архив не содержит базы, пользовательских файлов и секретов. Реальная установка выполняется на сервере пользователем; публикация архива VPS не обновляет. Автоматическое создание почтовых ящиков через API Beget по-прежнему не подключено.
