# Обновление АРМАДА 6.14.2

[Скачать архив](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.14.2-update.zip)

Один пакет поверх 6.14.0 или 6.14.1. Включает все предыдущие изменения: сначала сохраняется контракт, затем добавляются объекты; отдельный реестр договоров с контрагентами; карточки персонала без аккаунта; компактные документы техники; корпоративная иконка.

Почта: исправлено автоматическое прочтение, счётчик обновляется после чтения; компактные строки входящих/исходящих, отправитель, тема, короткая дата, выделение непрочитанных, фильтр «Непрочитанные», папки сбоку на компьютере и полосой на телефоне.

Уведомления: компактные строки вместо больших карточек. Оставлены работы на проверке, заявки, обращения и ошибки. Обычные сохранения и успешная отправка не увеличивают счётчик; полный журнал действий сохраняется отдельно.

Инструкция и проверки: FIX_MAIL_AND_NOTICES_6_14_2.md, FIX_CONTRACT_FIRST_6_14_1.md, UPDATE_BEGET_6_14.md. Перед обновлением создать резервную копию; базу и тома не очищать, руководителей повторно не создавать. Все пользовательские данные и почтовые реквизиты сохраняются.

Проверено: 514 серверных тестов PostgreSQL, целевые и браузерные проверки, локальный TLS IMAP, переход с 6.14.0 и восстановление копии. Настоящий VPS разработчиком не обновлялся; установка выполняется пользователем.

Папка архива: **openIA-feature-accounts-foundation**.
