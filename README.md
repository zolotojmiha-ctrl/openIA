# АРМАДА 6.17.1

[Скачать обновление](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.17.1-update.zip)

Исправления после проверки ЛК: скачивание Excel прямо из участка, доступ к общему списку дефектов, явные фильтры, возврат в исходный участок после импорта и сохранение контекста навигации. Включены все исправления предыдущих версий. Подробности RELEASE_6_17_1.md в архиве.

Перед установкой выполнить deploy/beget/backup.sh. Сохранить .env и тома базы, документов и ключей. Не создавать руководителей повторно.

Проверено: 573 основных теста PostgreSQL и 22 сценария Chromium; после уточнения фильтров ещё 72 проверки PostgreSQL и три проверки браузера/выгрузки. Новых миграций относительно 6.17.0 нет.
