# АРМАДА 6.27.0

Потребность по объектам/участкам, единое обозначение DN и настраиваемая рассылка потребности заказчику.

## Установка

Для существующей установки: используйте опубликованный установщик GitHub или передайте ZIP, install-6.27.0.sh и SHA256SUMS в один каталог сервера. От root:

    sha256sum --check SHA256SUMS
    bash ./install-6.27.0.sh

Штатный каталог: /opt/armada/openIA-feature-accounts-foundation. Для другого существующего расположения задайте ARMADA_APP_ROOT. Альтернативный ZIP задаётся ARMADA_UPDATE_ARCHIVE. Установщик проверяет SHA-256, собирает образ до замены исходников и создаёт резервную копию перед запуском новой версии. База, тома, документы и ключи не сбрасываются.

## Первый запуск рассылки

1. В «Потребности в муфтах» откройте «Рассылка заказчику».
2. Выберите доступный подключённый ящик отправителя, получателей и объекты/участки; при необходимости ограничьте контракты.
3. Проверьте предпросмотр и Excel; для разовой отправки нажмите «Отправить потребность сейчас».
4. Для автоматической рассылки включите еженедельное расписание и задайте день, время, часовой пояс.

Расписание по умолчанию выключено. Пакет не создаёт реального ящика noreply и не подключает почтового провайдера. Нужен подключённый ящик и действующие SMTP-настройки. Реальным заказчикам писем при подготовке не отправляли.

В письмо и Excel входит только потребность на оставшиеся работы. Наличие, резервы и дефицит не передаются и не вычитаются из количества. История сохраняет снимки и вложения; принятие SMTP-сервером не означает прочтение заказчиком.

DN меняет обозначение и выбор, а не физические размеры в базе. Для П1 DN 700 остаются труба 720 и оболочка 760 мм для изоляции. Нормы и остатки сохраняются.

## Проверки

Полный PostgreSQL: 1016 тестов, OK; заключительный профиль: 38 тестов, OK. Конечный ZIP-образ проверен на обновлении и восстановлении с 6.25.0, 6.25.1, 6.26.0. Сверено 626 файлов образа. Шесть проверок установщика прошли.

Исходный коммит: 615117145a4b1009ede7486aba5b66f18e2ef013. Производственной установки не было. Перед установкой после восстановления VPS сначала проверьте сохранность рабочих данных.

Яндекс Диск, нормы электродов и погонные метры рулонов не включены.
