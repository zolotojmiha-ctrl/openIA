# АРМАДА 6.16.2

[Скачать обновление](https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/openIA-6.16.2-update.zip)

Меню редактирования и удаления участков, удаление карточек договоров с проверкой связей, автоматическая подстановка контекста дефекта, явное открытие доступа мастеру при назначении, единая таблица и возврат к исходным фильтрам. Подробности RELEASE_6_16_2.md в архиве.

Перед установкой выполнить deploy/beget/backup.sh. Сохранить .env и тома базы, документов и ключей. Не создавать руководителей повторно.

Для этого исправления прошли восемь проверок, включая Chromium: удаление доступно из списка, отмена возвращает в список. Полный пакет включает проверенные изменения 6.16.1.
