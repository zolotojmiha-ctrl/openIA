# АРМАДА | Управление — обновление 6.28.0

Накопительный выпуск включает ранее подготовленные функции платформы и шифрованное резервирование на Яндекс Диск. Автоматическое резервирование по умолчанию выключено; фотографии пока хранятся прежним способом.

После восстановления сервера сначала проверить сохранность базы, документов и конфигурации. Установщик предназначен только для существующей установки: он проверяет архив, собирает образ и создаёт резервную копию перед обновлением. Он не создаёт новый сервер и не сбрасывает базу. При наличии файлов рядом запустить от root `sha256sum --check SHA256SUMS`, затем `bash install-6.28.0.sh`. Подробности подключения и восстановления находятся в архиве: docs/YANDEX_DISK_BACKUPS.md.

Для работы Яндекс Диска потребуется отдельно установить обработчик на VPS, безопасно ввести токен в личном кабинете, сохранить ключ восстановления и проверить создание и восстановление первой копии. Живое подключение к учётной записи владельца не проверялось. Для резервирования потребуется свободное место на VPS; локальные архивы автоматически не удаляются. Производственная установка не выполнялась.
