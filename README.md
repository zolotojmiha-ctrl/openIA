# АРМАДА — обновление 6.24.0

Аренда техники (10 / 4 / 0 часов, тарифы, авансы и сверка), потребность по ремонтам, комплекты П1 по РД, изоляция П2 и кабинет заказчика с документами и GPS.

Исходники: [неизменяемый коммит 1aa9e23fb936](https://github.com/zolotojmiha-ctrl/openIA/tree/1aa9e23fb936cabb296076962c6cb5aa2c147919).

## Готовые файлы

- [Архив 6.24.0](openIA-6.24.0-update.zip)
- [Установщик Beget](install-6.24.0.sh)
- [Контрольные суммы](openIA-6.24.0-update.sha256)
- [Метаданные и результат проверок](openIA-6.24.0-update.json)

Установщик рассчитан на существующую установку в `/opt/armada/openIA-feature-accounts-foundation`. Проверяет SHA-256/ZIP, собирает образ до замены файлов и создаёт резервную копию базы, документов, настроек и ключей. Данные и тома не сбрасываются. Переход и восстановление копии проверены с 6.22.2 и 6.23.0; непосредственная установка на рабочий сервер разработчиком не заявляется.

```bash
curl -fL --retry 3 'https://github.com/zolotojmiha-ctrl/openIA/raw/refs/heads/downloads/nas-updates/install-6.24.0.sh' -o /tmp/armada-update-6.24.0.sh &&
bash /tmp/armada-update-6.24.0.sh
```

После установки обновите страницу кабинета. Для расчёта изоляции П2 один раз настройте подтверждённые габариты и площадь конкретного типоразмера в «Материалы по ремонтам → Нормы изоляции». Рабочие расходы: Ксизол 5,19 кг/м², обёртка 0,81 кг/м², праймер 0,21 кг/м². 2,55 м²/м не переносится на все диаметры. Электроды отложены. Пока профиль не настроен или материала недостаточно, результат мастера сохраняется с ожидающим списанием и понятной причиной.

Полный прогон PostgreSQL: 911 проверок, OK; последующий профильный прогон 36 проверок, OK. Исходники, архив, конечный образ и установщик проверены отдельно. Старые пакеты сохранены в этой ветке как история выпусков.
