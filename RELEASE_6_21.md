# АРМАДА 6.21.0 — общие режимы складского списка

«Склады» открывает общую таблицу материалов. Вверху находятся две отдельные команды.

- **Редактировать список** — поля открываются прямо в таблице. Можно изменить несколько строк и нажать «Сохранить изменения» один раз. «Отмена» оставляет данные без изменений. Доступны наименование, склад, количество, дата и источник получения, заводские номера внутри строки. Категория и характеристики карточек без истории также редактируются; характеристики позиций с историей сохраняют прежние ограничения учёта.
- **Удалить** — появляются флажки выбора. Можно отметить несколько позиций или все строки страницы, затем нажать «Удалить выбранные». Подтверждение перечисляет материалы, склады и количества. Удаляются остатки выбранных строк на соответствующих складах; история операций и монтажа сохраняется. Для удаления закреплённых изделий сначала снимают назначение.

За один раз сохраняются строки открытой страницы (до 50). Фильтры сохраняются. При ошибке изменения остаются в таблице, запись в базу полностью откатывается. Если после открытия таблицы данные изменились другим действием, устаревшее сохранение отклоняется. Повтор одного успешно сохранённого запроса не создаёт дублирующих операций. Количество меняется через движения учёта; даты и источники исправляются с журналом изменений. Старую карточку без остатка можно поставить на выбранный склад прямо в таблице, указав фактическое количество.

## Закрепление за дефектами

Действие **«Закрепить за дефектами»** видно сразу у строки муфт. Оно открывает полноценную таблицу вместо выпадающего списка. Для каждой работы показаны контракт, участок, нефтепровод, километры, номера дефектов и секций, описание, тип ремонта, длина и состав конструкции, диаметр, стенка, мастер, плановая дата и состояние.

Доступны поиск и фильтр подходящих конструкций. Неподходящие варианты сопровождаются причиной: другой тип, диаметр, длина или стенка, закрытая работа либо уже закрытая потребность. Для нескольких муфт указывают количества напротив нужных конструкций и сохраняют все назначения вместе. При выборе одной конкретной муфты используется выбор одной работы; заводской номер можно указать тут же. Старые ссылки индивидуального назначения ведут на новый перечень.

Закрепление не уменьшает складское количество. Материал остаётся на складе до монтажа. Физический остаток нужен до назначения: карточка с нулевым количеством и без склада сама по себе не означает наличие изделия.

## Установка

Полный пакет с предыдущими функциями. Новых миграций нет. Перед распаковкой выполнить `bash deploy/beget/backup.sh`. Сохранить `.env`, базу, документы, постоянные тома и ключ почты. Собрать web и выполнить обычный compose up. Пользователей заново создавать не требуется. Версия после установки — 6.21.0.

Проверки выполняются на отдельных синтетических данных. Производственная база пользователя и реальная почта не используются. Общий прогон: 727 тестов PostgreSQL и 26 браузерных сценариев прошли. Дополнительно проверены сохранение нескольких строк одной операцией, откат всего набора при ошибке, защита от устаревшего сохранения и повтора, удаление только с выбранного склада, номера и даты получения, сохранение резервов другого изделия при индивидуальном назначении. Проверены обновление с 6.20.0 и восстановление резервной копии в отдельном Docker. Проверки конфигурации, миграций и JavaScript прошли.
