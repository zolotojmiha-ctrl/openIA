# АРМАДА 6.20.1 — материалы на основном экране складов

Исправляет навигацию и доступность редактирования после замечаний к 6.20.0. Главный рабочий экран «Склады» теперь открывает общий список материалов со столбцом текущего склада, количеством, резервами и монтажом. Название склада, например «Володя Барабинск», показывается в строке каждого числящегося на нём материала. Один типоразмер на разных складах остаётся разными строками.

Список мест хранения перенесён в дополнительное действие «Настроить склады»: там создают склад, меняют адрес, обслуживаемые участки/бригады и доступ. Для сотрудников только с правом просмотра склада сохранён прежний ограниченный доступ; права редактирования не расширяются.

## Редактирование

В каждой строке общего перечня есть видимая кнопка **«Изменить»**. Она открывает:

- фактическое количество на выбранном складе и причину его исправления;
- перемещение количества на другой склад;
- отдельные позиции с кнопками изменения характеристик и заводских номеров.

Количество исправляется учётным движением с указанной причиной. Остатки других складов сохраняются. Снижение ниже закреплённого количества и сохранение устаревшей формы отклоняются. Монтаж по-прежнему изменяется через результат ремонта.

## Старые позиции без склада

Для позиции с «Склад не указан» есть отдельная кнопка **«Указать склад и количество»** прямо в строке. Форма заполняется её характеристиками. Если доступен один действующий склад, он выбран заранее. Пользователь указывает фактическое количество и дату, затем сохраняет. Ранее созданная карточка без движений используется повторно: дубль вместо неё не создаётся. После сохранения открывается общий список, где склад и остаток показаны в строке материала.

Само наличие старой карточки не доказывает физический остаток. Обновление не назначает ей склад и не добавляет единицы без подтверждённого пользователем количества.

## Обновление

Полный пакет поверх 6.20.0. Новых миграций нет. Перед распаковкой выполнить `bash deploy/beget/backup.sh`, сохранить `.env` и постоянные тома, собрать web и выполнить обычный compose up. Версия после обновления — 6.20.1. Производственные данные пользователя при разработке и проверке не использовались.

Проверки: 170 целевых тестов PostgreSQL и пять браузерных сценариев склада прошли. В новом сценарии воспроизведена старая карточка без склада: открытие из меню → назначение склада и количества без дубля → изменение характеристик → исправление количества. Проверены размеры экрана 1440, 390 и 320 пикселей. В изолированном Docker прошли обновление с 6.20.0, сохранение данных, резервная копия и восстановление. Конфигурация, согласованность миграций и JavaScript проверены.
