Одна строка — один дефект. Один код ремонта объединяет дефекты под одной конструкцией на одном километре (округлённом до трёх знаков). Для второй муфты укажите другой код ремонта, даже если её установили в тот же день.

Заполните телефон мастера, имеющего доступ к выбранному объекту. Пустой телефон оставляет ремонт без назначения; его можно назначить после импорта. Один файл относится к одному участку. Километры округляются до трёх знаков. Номера дефектов и секций — только цифры; стенка муфты — целое число. Старые названия колонок также поддерживаются.
