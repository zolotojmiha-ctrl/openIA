Импорт Excel

Сначала создаются компании и поручения, затем представители, доступы, связи с документами и дефекты. Даты — ГГГГ-ММ-ДД. Новые записи — пустой ID; для изменения карточки сохраняйте ID и версию. Для привязки ремонта укажите его существующий ID и версию.

Виды: repairs — дефекты; valves — замена арматуры; diagnostics — подготовка к диагностике; construction — другие СМР. Результаты: complete — выполнено; partial — частично; problem — препятствие. Количество — выполнено с начала работ, не за день.

Результаты с ID не переписываются. Файлы загружаются отдельно. Удаление строки не удаляет запись. Каждый новый импорт строк без ID считается новыми данными. До 500 строк; ошибка любой строки отменяет перенос.
