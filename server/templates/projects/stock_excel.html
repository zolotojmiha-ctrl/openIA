Импорт складских данных

Сначала загрузите склады и номенклатуру, затем операции. Даты — ГГГГ-ММ-ДД. Новая строка — пустой ID. Для существующей карточки сохраните ID и версию. Удаление строки не удаляет запись.

Операции: receipt — поступление; transfer — перемещение; issue — выдача бригаде; return — возврат; consume — списание на работу; loss — недостача / другое списание. Проведённую операцию нельзя переписать: отмените её и добавьте новую. Новые строки без ID при повторной загрузке другого файла считаются новыми операциями.

Остатки выгружаются отдельно. Для их изменения проводятся поступления, выдачи и списания. Формулы не исполняются. До 500 строк за перенос.
