Загрузить остатки и распределение из Excel

Сначала скачайте файл обмена. В «Остатках» меняйте новый остаток и наименование; в «Распределении» — работы и количества; в «Изделиях» — номера, источник, склад и назначение конкретного изделия. Для повторной поставки заполните «Количество нового поступления», её дату и источник; новые строки того же типоразмера также разрешены. Частичные перемещения указывайте на листе «Перемещения». Коды и версии не меняйте. Работы копируйте с листа «Работы».

Для строки с «Обновить распределение = да» загрузится полное распределение: отсутствие назначения в файле снимет прежний резерв. Изменение остатка оформляется отдельной складской операцией. Монтаж через остатки не оформляется. При изменении назначения отдельной муфты оставьте групповые количества без изменений; совмещать два способа распределения в одной строке нельзя.

Новую позицию добавляйте с кодом НОВАЯ-1, НОВАЯ-2 и т.д., названием существующего склада, характеристиками, количеством и датой получения. Для нового назначения используйте этот же код на листе «Распределение». Существующей карточке без остатка можно указать склад и начальное количество. Изменение склада в основной строке переносит весь её остаток; для части количества используйте лист «Перемещения». Файл не истекает по времени, но проверяется по фактическому состоянию базы.
