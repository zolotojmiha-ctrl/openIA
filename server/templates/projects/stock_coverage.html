Обеспеченность муфтами

{% if scoped %}Потребность выбранного контракта / участка.{% else %}Потребность всех доступных незавершённых работ.{% endif %} Свободный запас — по всем доступным складам, без чужих резервов и смонтированных изделий. Для П1 и П2 подходит муфта того же типа и диаметра с длиной и стенкой не меньше требуемых. Одна муфта покрывает одну часть конструкции.

Состав конструкции задаётся в метрах, например 1+1.5: потребуется две муфты 1000 и 1500 мм. Пустой состав при известной длине означает одну цельную муфту. Неоднозначные записи перечислены отдельно и не считаются обеспеченными.

Свободные муфты учитываются в расчёте однократно. Этот подбор не закрепляет их за дефектами автоматически.
