# deploy/hotfixes: канал закрыт (6.33.1)

Файлы `install-*.sh` в этом каталоге - заглушки: они печатают отказ и завершаются с кодом 3 до любых действий.
Исторические версии сохранены только для истории в `historical/*.disabled` (не исполняемые; в установочный пакет не включаются).

Что это не делает: уже скачанные владельцем старые скрипты отозвать нельзя. Эталон нового дерева - состав конкретного проверенного подписанного выпуска; частные файлы `.env*` и явно разрешённые параметром `--allow-local-files` дополнительные файлы учитываются отдельно.
