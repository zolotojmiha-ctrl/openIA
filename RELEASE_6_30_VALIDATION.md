# Подготовка АРМАДА 6.30.0

Статус на момент фиксации исходного коммита: пакет ещё не проверен, к установке не допущен. Подготовка разрешена владельцем 8 ноября 2026 года. Ветка feature/cabinet-6.30.0.

База — проверенная интеграция MAX: 1111 тестов PostgreSQL 17/Chromium на 9fc55ce, отдельный образ и фактическое восстановление синтетического дампа с привязкой/черновиком/фото. Эти результаты не заменяют проверку установочного выпуска 6.30.0. Полный протокол разработки — docs/MAX_VALIDATION.md.

Для выпуска изменены номер версии, описание и установщик. Новый ZIP формируется из неизменяемого коммита с прежним корнем openIA-feature-accounts-foundation. Токены, рабочие данные, .runtime и служебная среда не включаются.

До готовности: проверить конечный образ/файлы/версию; штатное резервирование, переходы с 6.25.0/6.25.1/6.26.0/6.27.0/6.28.0/6.29.0 и восстановление исходных архивов; собственный архив 6.30.0 с MAX и выключенными внешними отправками; защиты установщика, затем контрольные суммы. Итоговый протокол рядом с ZIP содержит исходный коммит, хэши и фактический статус. Этот файл внутри исходного ZIP сохраняет состояние на момент фиксации, внешний протокол обновляется только после испытаний.

MAX выключен до настройки и пилота. Настройки и секреты прежних установок сохраняются; ранее работавший MAX-worker при повторной установке проверяется отдельно. На рабочий VPS не обращаться, новый выпуск на GitHub в ходе локальной подготовки не публиковать, 6.29.0 не переписывать.
