# АРМАДА 6.16.2

В списке контрактов рядом с «Открыть» добавлено меню «⋯»: редактировать и удалить контракт. В списке договоров контрагентов такое же меню. Удаление открывает подтверждение; отмена возвращает в исходный список. Права руководителя и существующие проверки связанных записей сохранены. Внутри карточки действие удаления также остаётся.

Пакет включает все изменения 6.16.1. Устанавливается поверх 6.16.0 или 6.16.1 после deploy/beget/backup.sh, с сохранением .env и томов. Затем docker compose -f deploy/beget/compose.yml build web и docker compose -f deploy/beget/compose.yml up -d.
