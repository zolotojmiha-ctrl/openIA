# Согласованный выпуск 4 — документы и финансы

Основание: ТЗ v0.8 и последующие прямые ответы владельца. Поздние ответы заменяют противоречащие положения ТЗ. Этот файл не содержит реальных реквизитов, учётных данных или исходных документов компании.

## Документы

- Обязательное утверждение загруженных файлов отменено. Исторические решения не уничтожаются. Подтверждение принятого финансового выполнения остаётся полномочием двух руководителей.
- По умолчанию документ доступен автору и двум руководителям. Назначение на объект не раскрывает вложения. Автор и руководители открывают/отзывают доступ. Получатели не передают его дальше.
- Два уровня: чтение/скачивание и дополнительно новые версии. Комплекты имеют свои разрешения, распространяемые на будущие вложения; отдельные файлы можно открыть отдельно. Явный запрет файла сильнее доступа комплекта.
- Входящие и личный счётчик: новые доступные документы и версии, собственные загрузки исключены; прочтение отдельно для каждого пользователя после открытия карточки. Никаких утверждений.
- Пакетная загрузка, повтор только неудавшихся файлов, общие связи/раздел/получатели для пачки. Все расширения принимаются как закрытые вложения; исполняемые форматы на сервере не запускаются. Сохраняются ограничения размера и контроль целостности.
- Название по умолчанию из файла, обязательный тип/раздел. Связи, номер, дата, комментарий необязательны. Сроки не усложняют загрузку: отдельные личные напоминания.
- Разделы: договоры и приложения, персонал, журналы, исполнительная документация, акты/сметы, чертежи/схемы, фото/видео, прочее. Именованные комплекты, основной документ и приложения.
- Совпадение только по названию внутри выбранного места загрузки и доступных документов: заменить (новая версия) или оставить оба с суффиксом. Применение решения ко всем совпадениям. Чужие закрытые файлы не раскрываются.
- Карточки договора/объекта/сотрудника показывают доступные связанные файлы; загрузка из карточки подставляет связь. Один файл, несколько связей.
- Пропущенная ожидаемая связь: предупреждение, сохранение «На разбор», массовое назначение; действие «Связь не требуется». Отдельный от непрочитанных счётчик.
- Архив: автор/руководители архивируют и восстанавливают, остальные файл не получают. Полного удаления нет. История версий/связей/авторов сохраняется.
- Просмотр PDF/изображений/текста внутри кабинета, прочие форматы скачиваются. Поиск по доступным метаданным/связям, фильтры, понятное местонахождение. Глобальный поиск по умолчанию.
- Комментарии, обращение внимания выбранных получателей с доступом, избранное, личные напоминания. Отзыв доступа действует на поиск, прямые ссылки, уведомления и избранное; скачанные копии забрать нельзя.

## Персонал и удобство

- Карточка работника отдельно от входа в кабинет; сварщикам учётная запись не нужна. Назначенные ответственными пользователи создают карточки, документы и назначения на объекты. Выгрузка выбранных доступных документов по людям в ZIP.
- Увольнение: блокировка учётной записи и завершение сеансов при её наличии, карточка в архиве; история/документы сохраняются; передача ответственности выбранных/всех файлов. Возможность восстановления.
- Подсказки по умолчанию, отключаемые индивидуально; мышь/клавиатура/нажатие на телефоне. Существенные последствия видны независимо от подсказок.
- Профиль: статус/права, пароль, активные сеансы, уведомления, подсказки, размер текста, плотность списка. Самоназначения прав нет.
- Обращения сотрудников: новое/в работе/решено. Руководители видят все, автор — свои.
- Главная: входящие, на разбор, напоминания, избранное, поиск/загрузка; обращения и финансовая аналитика руководителям.

## Финансы — включены в выпуск

Ручной ввод. Договорная цена и изменения, индивидуальный НДС, фактическое и принятое выполнение, авансы/зачёты, поступления с ручным распределением бухгалтером, ещё не наступившая/просроченная задолженность, обязательства субподрядчикам, прямые/накладные затраты, плановая прибыль, результат по выполнению и денежный поток раздельно. Общие затраты автоматически по объектам не распределяются. Сверка источников. Один из двух руководителей подтверждает принятие выполнения.

Недостающие договорные правила не подменять формулами: условия зачёта аванса, дата/срок оплаты и интерпретация НДС. Запрошен условный пример зачёта и срока оплаты. До подтверждения автоматические договорные расчёты не реализовывать как утверждённые.

## Приёмка

- Одна загрузка договора + 20 приложений, частичная ошибка без повторного сохранения успешных файлов.
- Доступ экологу без раскрытия мастеру: список, поиск, связи, ZIP, предпросмотр, старая прямая ссылка, отозванный доступ.
- Раздельное прочтение двумя руководителями, новая версия/открытие доступа, исключение собственных загрузок.
- Новые версии, архив, переносы, персонал и комплекты сохраняют историю; права при изменении связи показаны явно.
- Финансовые суммы/зачёты не дублируются; распределение не превышает платёж; долги/авансы/денежный поток разделены; посторонние пользователи не получают суммы.
- Прежние данные и файлы сохраняются; миграция, PostgreSQL, восстановление, проверка UI компьютера/телефона.
- Публичный сайт не заменяется; NAS/семейные папки не монтируются; новая версия имеет отдельный тег образа и видимый номер.
