# Главная руководителя

Карточки с ненулевыми показателями на главной руководителя отображаются перед карточками с нулём; сами карточки и ссылки сохранены. Для руководителя не показывается блок «Дополнительно выданные полномочия»: его права не являются отдельно делегированными, переходы к разделам доступны через существующее меню и рабочие блоки. Для сотрудников с индивидуально выданными правами блок сохранён. На правах и расчёте показателей это не отражается. Проверяются порядок карточек, экраны ролей и доступность разделов. Локальные изменения, без выпуска и установки.
