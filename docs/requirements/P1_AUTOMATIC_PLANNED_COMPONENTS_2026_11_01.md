# Автоматический состав П1 для плановой потребности

**Позднейшее разрешение:** владелец поручил подготовить обновление со всеми замечаниями. Реализация и актуальные границы — [RELEASE_6_25.md](../../RELEASE_6_25.md); прежняя просьба не выпускать ниже описывает прошлый этап.

Статус: уточнение владельца от 1 ноября 2026 года. Только требования; владелец явно запретил пока готовить обновление. Код, миграции, база и опубликованный пакет не изменяются.

## Подтверждённые правила

- В разделе потребности отображать только отдельные изделия типовых длин, если они требуются: **П2 — 1000 и 1500 мм; П1 — 1000, 1500, 2000 и редко 2500 мм**. Общие длины составных конструкций, например 3000/4000 мм, не выводить как длины закупаемых одиночных муфт.
- Программа сама рассчитывает плановый состав П1. Не требовать от пользователя предварительно вписывать состав каждой конструкции для получения потребности.
- При стыковке возникает кольцевой сварной шов. Предпочитать план с меньшим количеством стыков: для n соединяемых муфт — n−1 кольцевых стыков между ними. Это счёт стыков составной конструкции, а не всех сварных швов ремонта.
- **П1 4000 мм для планового расчёта — только 2000 + 2000 мм**, один кольцевой стык. Три такие конструкции дают потребность **6 шт. П1 2000 мм** с соответствующим диаметром и стенкой, а не 3 шт. по 4000 мм.
- **1500 + 1500 + 1000 мм не использовать как автоматический план для 4000 мм**: два кольцевых стыка хуже для заказчика. Такой состав может быть внесён по факту монтажа, но не должен подменять утверждённое правило планирования.
- Все элементы одной составной П1 имеют одинаковую стенку, не меньше требуемой. П2 не стыкуется.
- Не смешивать автоматический план потребности, складское закрепление и фактический монтаж. Расчёт потребности сам по себе не резервирует и не списывает изделия. Факт может отличаться от плана и сохраняется отдельно.

## Границы трактовки

Это уточнение заменяет прежнюю трактовку «программа не выбирает состав, пока сотрудник его не ввёл» именно для плановой потребности. Выбор и подтверждение фактических изделий остаются отдельным действием.

Для 4000 мм действует явное правило 2000 + 2000, даже если есть другая комбинация с тем же числом стыков. В частности, нельзя подменять его вариантом 2500 + 1500, ссылаясь только на минимальное число элементов. Редкость 2500 мм не означает полного исключения этого размера из разрешённого перечня. Полная таблица предпочтений для остальных длин и условия планового использования редкой длины 2500 мм этим сообщением не заданы; не выдавать собственные предположения об этих предпочтениях за слова владельца.

Общий предел П1 10500 мм и прочие ранее согласованные правила сохраняются. Для суммирования учитывать одну общую ремонтную конструкцию однократно, даже если она закрывает несколько дефектов.

Дополнительный ответ владельца при подготовке выпуска: для П1 2500 мм в плановой потребности считать **одну муфту 2500 мм**. Реализованный выбор остальных составов описан в RELEASE_6_25.md; он уменьшает число стыков, при равенстве предпочитает меньше редких изделий.
