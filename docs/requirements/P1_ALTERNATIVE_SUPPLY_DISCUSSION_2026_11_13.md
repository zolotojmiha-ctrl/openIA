# Варианты состава П1 — обсуждение, отдельно от ошибки учёта закрепления

Во время исправления потребности владелец отметил: для П1 общей длиной 3000 мм оба варианта 2000+1000 и 1500+1500 верны; на практике он предпочитает 1500+1500, чтобы кольцевой стык был посередине. Спрашивает, стоит ли показывать альтернативную потребность и не запутает ли это заказчика. Прямого поручения менять правило выбора ещё нет.

Предложено: одна утверждённая потребность для заказчика. Внутри ЛК выбор планового состава по конкретному километру; после выбора пересчитываются сводка/письмо/Excel, варианты не суммируются. При отсутствии выбранных/закреплённых изделий для 3000 мм предложен основной вариант 1500+1500. Уже закреплённый совместимый комплект имеет приоритет; замена реальных резервов требует отдельного явного действия, а не молчаливого перерасчёта.

Это предложение для следующего этапа. Текущий пакет RESERVED_P1_DEMAND исправляет учёт реально закреплённого комплекта и не меняет ранжирование автоматического плана для свободного ремонта 3000 мм. Старое правило 4000=2000+2000 сохраняется. Не объявлять выбор альтернативных планов реализованным этим пакетом.

Уточнение владельца: предпочтение закупочного состава не распространяется на использование наличия. Складской подбор должен рассматривать все доступные работы совместно и использовать те комбинации, которые реально имеются сейчас. Его гипотетический пример: ремонт 1500 мм и ремонт 3000 мм, в наличии 1500×2, 1000×1, 2000×1. Правильный выбор — первая работа получает 1500×1, вторая — 1000+2000; остаётся одна 1500, закупка не требуется. При наличии для 3000 мм только двух 1500 должен выбираться этот вариант. Нельзя сначала израсходовать обе 1500 на длинную работу и создать искусственную нехватку для короткой.

Это обязательное условие дальнейшей доработки: закупочный предпочтительный состав и глобальное распределение наличия — разные решения; существующие закрепления учитываются первыми, затем совместно подбираются альтернативы для остальных работ, закупается только реальный остаток. Наличие/склад/область доступа, тип, диаметр, одинаковая допустимая стенка и предел 10,5 м должны сохраняться. Текущий пакет исправляет учёт уже закреплённого комплекта, не объявляет реализованным полный автоматический перебор складских вариантов или новый интерфейс их выбора.

Владелец подтвердил: цель совместного складского подбора — устранить как можно больше дефектов имеющимися сейчас муфтами, поскольку у заказчика проблемы с поставками. При дальнейшем проектировании критерием служит число закрываемых дефектов (общий ремонт может закрывать несколько), а не только число готовых ремонтов или симметрия/минимум стыков. Один общий комплект расходуется один раз; его польза учитывает закрываемые дефекты. Существующие установки и подтверждённые закрепления не перераспределяются молча. Потребность на закупку рассчитывается после распределения свободных остатков. Точный общий оптимизатор со всеми вариантами состава в текущем пакете не реализован; это отдельный следующий этап, с самостоятельными проверками и границами масштабирования.

Следующий этап реализуется отдельно после подтверждённой установки RESERVED_P1_DEMAND. Актуальные требования и ограничения совместного подбора: [GLOBAL_COUPLING_ALLOCATION_2026_11_13.md](GLOBAL_COUPLING_ALLOCATION_2026_11_13.md). Описания выше фиксируют состояние прежнего пакета, а не отсутствие новой реализации.
