# Варианты состава П1 — обсуждение, отдельно от ошибки учёта закрепления

Во время исправления потребности владелец отметил: для П1 общей длиной 3000 мм оба варианта 2000+1000 и 1500+1500 верны; на практике он предпочитает 1500+1500, чтобы кольцевой стык был посередине. Спрашивает, стоит ли показывать альтернативную потребность и не запутает ли это заказчика. Прямого поручения менять правило выбора ещё нет.

Предложено: одна утверждённая потребность для заказчика. Внутри ЛК выбор планового состава по конкретному километру; после выбора пересчитываются сводка/письмо/Excel, варианты не суммируются. При отсутствии выбранных/закреплённых изделий для 3000 мм предложен основной вариант 1500+1500. Уже закреплённый совместимый комплект имеет приоритет; замена реальных резервов требует отдельного явного действия, а не молчаливого перерасчёта.

Это предложение для следующего этапа. Текущий пакет RESERVED_P1_DEMAND исправляет учёт реально закреплённого комплекта и не меняет ранжирование автоматического плана для свободного ремонта 3000 мм. Старое правило 4000=2000+2000 сохраняется. Не объявлять выбор альтернативных планов реализованным этим пакетом.
