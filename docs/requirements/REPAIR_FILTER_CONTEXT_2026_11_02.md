# Ведомость дефектов: сохранение выбранного состояния

При поиске по номеру, километру или другим полям сохраняется выбранная вкладка состояния работ: например, поиск внутри «Устранены — на проверке» не возвращает в список всех работ. Для смены состояния остаются вкладки над ведомостью. При переходе к результатам «На доработке» и «Не подлежат устранению» из архива сохраняется признак архива. Права, расчёт количества и сами статусы работ не менялись.

Проверяется отправка фильтра в браузере, а также отображение архивных переходов. Изменения подготовлены в исходниках и не установлены.
