# Идея владельца: приём электронных чеков через MAX

В ходе согласованной реализации фото хода работ владелец предложил отдельную функцию: отправлять через бота фотографии чеков самозанятых за выполненные работы и другие электронные чеки, сохранять их и направлять технику на проверку. Спросил мнение; реализация этой дополнительной идеи пока не согласована.

Предложен отдельный пункт «Чеки»: фото/PDF → необязательная привязка к контракту/участку/работе → хранение → очередь назначенного техника. Допустимо сохранить без привязки для последующего разбора. Статусы «На проверке», «Проверен», «Нужно уточнение», дополнение реквизитов и вопрос отправителю. Доступ отправителю, назначенному проверяющему и сотрудникам с соответствующими разрешениями. Проверка файла не создаёт оплату/проводку или повторный расход. Конкретный проверяющий, перечень проверяемых реквизитов и связь с бухгалтерским учётом требуют отдельного согласования. Проверку по ФНС/QR или автоматическое распознавание не объявлять готовыми. Секреты, реальные чеки и персональные данные в Git не вносить.

Активная реализация остаётся «Фото хода работ», идея чеков её не отменяет.
