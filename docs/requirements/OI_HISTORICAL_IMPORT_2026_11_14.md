# Исторический импорт Омск — Иркутск

Согласованная область: исторические дефекты МН Омск — Иркутск по участкам от Омска до Анжеро-Судженска, начиная с 2024 года, из предоставленной владельцем рабочей книги. УБО, Омск — Павлодар и вспомогательные расчёты исключаются. Данные книги и раскладок частные, их содержимое/производственные идентификаторы в Git не помещать.

Уточнение владельца: действующая база ЛК заполнена правильно и не должна изменяться. Нельзя автоматически обновлять, объединять с историей, архивировать или переназначать существующие работы, дефекты, отчёты, назначения, часы, остатки, резервы и права. Возможные совпадения с текущей базой проверять только чтением и показывать до переноса, без изменения текущей записи.

Историческая загрузка должна быть отделена от текущей работы. Устранённые исторические дефекты сразу помещаются в доступный для просмотра архив. Они не попадают в текущие списки мастеров, потребность, подбор и уведомления. Статус/причина неустранения переносятся только при подтверждающих данных; неясные случаи выделяются отдельно и не становятся текущими заданиями автоматически. Способ размещения неустранённой истории требует отдельного согласования перед записью.

Контракты прежних лет и соответствие работ им владелец предоставит отдельно с пояснениями. Не создавать вымышленные контракты, не привязывать старые годы к текущему контракту, не начинать производственную загрузку без сопоставления. Пользователь попросил выполнять этапы по порядку.

Первый этап — подготовить недостающий участок «ОИ Анжеро-Судженск — Сокур» без исторических дефектов и без назначения бригад/прав/текущего контракта. В рабочем ЛК по сообщению владельца этого участка пока нет. Факт создания на VPS не подтверждён. Далее — контракты, проверочная ведомость и отдельно подготовленная загрузка. Из среды разработки рабочая база не читается и не изменяется без отдельного доступа/установочного действия владельца.

Пять раскладок получены. В названиях «Барабинск — Татарская (лупинг)» и «Чулым — Барабинск (лупинг)» слово «лупинг» по прямому уточнению владельца обозначает название основной нитки этих участков, не дополнительную нитку. Для Анжеро-Судженск — Сокур исходное имя также сохраняется без самовольного создания дополнительной нитки. Раскладки — справочник секций, не перечень дефектов.

Расстояние требуется только между началами секций, без поправок на положение дефекта внутри секции. Используются длины секций и дистанции начала с проверкой последовательности. Порог предупреждения о привлечении трала — строго более 6000 м вдоль трубопровода; дорожный маршрут и время перевозки оцениваются отдельно. Реализация расстояний и исторический импорт — разные этапы; импорт архива не должен выдавать заявки/уведомления о трале.

Уточнения для чтения книги: первоначальный лист может содержать план; повтор на следующем рабочем листе с датой по пояснению владельца означает факт, особенно при закраске. Будущая дата не является выполнением. Неясные даты/события игнорируются без догадок. Цвет без контекста не даёт основания массово подтверждать выполнение. Сохраняются происхождение (файл, лист, строки), история редакций и отдельно даты монтажа/окончания ремонта. Фактические размеры согласованной сборки могут превышать требуемые за счёт наличия; не считать это автоматически ошибкой. Фактическое покрытие, расход, списание и часы по длине муфты не выдумываются.

Все новые пользовательские действия должны быть доступны полностью в ЛК и MAX согласно AGENTS.md. Производственный архив не импортирован; создана только локальная первичная ведомость кандидатов, без окончательной классификации статусов, контрактов и сопоставления с рабочей базой.
