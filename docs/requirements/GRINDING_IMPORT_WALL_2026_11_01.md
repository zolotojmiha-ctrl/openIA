# Импорт шлифовки: игнорировать случайно заполненную стенку муфты

Статус: требование владельца от 1 ноября 2026 года. Только сохранить договорённость; обновление, код и миграции пока не готовить.

Владелец получил при импорте XLSX ошибку «стенку муфты укажите только для метода ремонта муфтой» для строки со шлифовкой. Он потребовал вместо ошибки игнорировать ошибочно заполненное значение стенки муфты.

Будущее поведение:

- Если метод ремонта — «Шлифовка», содержимое столбца «Толщина стенки муфты, мм» не препятствует импорту и не требует ручной очистки Excel.
- Значение игнорируется до проверки его числового формата; в план шлифовки стенка муфты не записывается и в расчётах не участвует.
- Не менять метод ремонта, номера дефекта/секции, километр и остальные данные строки. Сохранить исходный загруженный файл и исходные данные для истории.
- Для ремонта муфтой сохранить проверки толщины стенки и прочих параметров. Другие ошибки импорта не скрывать. Автоматическую очистку ранее внесённых записей этим требованием не разрешали.

Текущий код 6.24.1: server/repairs/excel.py, parse_standard сначала проверяет числовой формат стенки, затем отклоняет заполненную стенку для метода без муфты. Эта запись описывает требуемое изменение, а не уже исправленное поведение.
