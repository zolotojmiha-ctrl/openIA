# Ведомость выполнения для ПТО

В существующих списке дефектов и ведомости участка добавлена кнопка «Ведомость выполнения». GET-раздел /cabinet/repairs/completed/ показывает фактические результаты по доступным данным. Фильтры и экспорт используют одну выборку. Это новый отчёт для сверки; старый Excel для импорта не изменён. Детали: requirements/PTO_COMPLETION_REGISTER_2026_11_13.md.

Дата и метод из последнего результата, покрытие из сохранённого замера, а не из плана. Старые отсутствующие сведения не выдумываются. В общей работе разные дефекты представлены строками с объединёнными фактическими значениями; в Excel длины числовые только в первой строке общей работы, связь по полному коду. Итоги считаются по уникальным работам на всех страницах. При просмотре ничего не изменяется; скачивание оставляет стандартную запись аудита. Новых моделей/миграций, прав, изменений запасов, закрытых результатов или MAX-привязок нет.

Проверено: 10 профильных SQLite-тестов OK; 101 PostgreSQL-тест (ведомость, старые repairs, проверки результатов, доступ) OK/27,847 с. Браузер после исправления ожидания перехода проходит на ширинах 320/390/1440: общая конструкция, горизонтальное прокручивание таблицы без распирания страницы, фильтр дат/мастера/контракта, скачивание Excel, возврат из карточки с фильтрами. После уплотнения фильтров и расположения фактического замера повторно 11 тестов SQLite/Chromium OK/9,180 с. Первая браузерная проверка упала из-за чтения таблицы до завершения перехода; ожидание исправлено в тесте. После этого прикладной формат не подменялся ради проверки.

Результаты реальной базы и пересчёт производственных данных не запрашивались. Проверки использовали синтетические записи. Пользователь подтвердил установку предыдущего пакета напоминаний (Healthy трёх служб, проверка Django без ошибок, статус привязки/ответственности и очередь sent); это сообщение владельца, не прямой доступ разработчика к VPS. Будущий установщик сохраняет новую версию rental_views.py с хэшем 66ad06efad11708b4cc8b2e10f2d02b9b0844fb0d23ff5a47201383b65ec712e.

Прогнозный график и мастерская смена метода после ДДК — отдельные обсуждения, этим пакетом не реализуются. Ближайшие заметки о прогнозе: requirements/REPAIR_FORECAST_IDEA_2026_11_13.md.

Заключительные 12 тестов PostgreSQL/Chromium OK/14,802 с: добавлена проверка итогов и экспорта за всеми страницами, в том числе покрытия после шлифовки без длины конструкции. Снимки только синтетического стенда сохранены вне Git. Отдельный новый Docker-образ этого пакета в облаке не собирался; приложение и настоящий браузер проверены с рабочими зависимостями, PostgreSQL 17 из локального образа, без доступа к производственным системам.
