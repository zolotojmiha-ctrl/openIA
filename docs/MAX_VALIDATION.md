# Проверка интеграции MAX

Статус: локальная реализация проверена и готова к закрытому пилоту; действующий бот не подключён. Ветка `feature/max-report-prototype`, база — опубликованные исходники 6.29.0 и отдельный офлайн-прототип. Производственный Beget, Figma, реальные письма и сообщения не затрагивались. Данные тестовые. Токен в чат не получен.

## Реализация

Постоянные привязки и черновики, одноразовая привязка с подтверждением в ЛК, отзыв, webhook с секретом/лимитами/дедупликацией, очередь обработки, пошаговая штатная форма ремонта, проверка сводки, закрытые фотографии, идемпотентная запись, уведомления о возврате со ссылкой на ремонт. Отправка отделена от решения руководителя; неопределённые ответы сети не повторяются автоматически. Устаревшие меню и уведомления проверяют действующий доступ. Запоздалый текстовый ответ отклоняется по времени события MAX.

Добавлены только миграции приложения maxbot; другие схемы и опубликованный пакет 6.29.0 не меняются. Сервис maxworker включается явно через профиль Compose. Резервирование останавливает только реально работающие писатели и возобновляет тот же набор; после ошибки тоже. Секреты поддерживают файловые настройки, MAX по умолчанию выключен. Руководство: [MAX_SETUP.md](MAX_SETUP.md).

## Граница готовности

Не выполнялись реальные `/me`, регистрация подписки, загрузка с реального CDN MAX, отправка действующему боту и пилот. Источники CDN по умолчанию пусты и требуют проверки на реальных событиях. Облачная политика и отсутствие безопасно настроенного токена не позволяют подтвердить реальный API здесь. Для пилота нужен доступный HTTPS-сервер; Beget не трогали.

Новый установочный выпуск/обновление с поддерживаемых прежних версий и полный хостовый архив резервирования ещё должны быть проверены перед публикацией установочного пакета. Выполненное восстановление синтетического дампа и файлов не заменяет испытание будущего установщика. ИИ и голос не реализованы. Сиротские файлы после аварии между записью и фиксацией метаданных автоматически не удаляются. Внешняя доставка сообщения не имеет гарантии strictly-once.
