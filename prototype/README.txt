КЛИКАБЕЛЬНЫЙ ПРОТОТИП АРМАДА — ВЕРСИЯ 2

Скачайте index.html и откройте его в браузере на компьютере двойным щелчком.
Установка, сервер, пароль и подключение к NAS не нужны.
Вверху можно переключить должность.
Рабочий пример дефектов: Контракты и работы → №ТЗС-1726-2025 → Работы → Омск–Татарск.
Проверка руководителя: Главная → Открыть очередь → выбрать результат → Подтвердить выбранные.
Мастер: выбрать должность Мастер → Открыть задания моей бригады → Внести результат.

Только демонстрационные данные. Изменения сбрасываются при обновлении страницы.
Реальные права, загрузка вложений и сохранение на сервере не реализованы.
Импорт и экспорт XLSX работают локально для демонстрационных реестров.
Общий раздел Документы показывает все документы. Из карточки сотрудника — его документы.
Создание компаний: Субподрядчики → Добавить.
Создание складов: Склады → вкладка Склады → Добавить.
Excel: Экспорт → редактирование с сохранением ID → Импорт → Проверить → Применить.
Новая строка — пустой ID; неизвестный или повторный ID отклоняется.
Не используйте реальные персональные или рабочие данные в прототипе.
Второстепенные кнопки могут показывать пояснение вместо рабочего действия.
Прототип не обновляет NAS и не содержит данных сотрудников.
