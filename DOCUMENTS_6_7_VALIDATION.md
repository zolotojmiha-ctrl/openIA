# Проверка 6.7.0-documents

- SQLite: 366 функциональных сценариев прежних и нового разделов прошли.
- PostgreSQL 17: полный финальный прогон 385 сценариев прошёл (87,171 с), включая две новые проверки одновременных сборок: повтор одного запроса создаёт одну версию, встречные сборки блокируют документы в одном порядке и отклоняют устаревший источник.
- Девять браузерных сценариев всех этапов прошли (71,334 с). Новый сценарий проверяет выбор сохранённых сканов, загрузку фотографии, изменение порядка, сохранение PDF, дату и напоминание, настоящий экспорт и повторный импорт XLSX, ширины 320/390/768/1440.

- Проверены оригинальные байты, число страниц полученного PDF, неизменяемая история, отсутствие автоматического копирования прав, отзыв доступа, устаревшие формы, повреждённые исходники, пароль PDF, лимит страниц, белый фон прозрачных палитровых PNG, очистка файлов после ошибки записи, запрет изменения документов архивного контракта.
- Проверены выключенное по умолчанию напоминание, порог даты, соблюдение доступа, версия карточки и атомарность Excel-импорта.
- Начальный PostgreSQL-прогон выявил особенность теста потокового ответа внутри TestCase: ручное закрытие ответа закрывало транзакционное соединение теста. Для новых файловых сценариев применён TransactionTestCase, как в существующих тестах документов; повторный полный прогон прошёл.
- Django check, проверка отсутствия незаписанных миграций и git diff --check прошли. Контейнер собирается из локальных колёс с обязательной проверкой SHA-256, без скачивания зависимостей при сборке.
