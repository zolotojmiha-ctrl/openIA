# Проверка выпуска 6.0.0-repairs

Дата: 20 октября 2026, часовой пояс Омск. Проверки выполнялись на отдельных учебных данных в облачной среде. Подключение к пользовательской Synology и установка на ней не выполнялись.

## Сервер и браузер

Полный прогон регрессии существующей платформы и нового модуля: **176 тестов на PostgreSQL 17, OK**, без пропусков. Отдельный прогон финальной редакции модуля: **41 тест на PostgreSQL 17, OK**, включая дополнительные проверки снятия препятствия и обработки чрезмерного числового порядка в XLSX. Эти количества перекрываются и не суммируются.

Проверены:

- Доступ только к назначенным работам в разрешённых объектах; закрытые работы не раскрываются через поиск, прямые ссылки, файлы или подбор муфт.
- Оба руководителя имеют одинаковые права. Мастер не может подтвердить выполнение, приёмку или изменить подтверждённый результат.
- Одна конструкция для нескольких дефектов; частичный результат, независимые материалы и препятствия; снятие препятствия без закрытия ремонта.
- Отдельная приёмка заказчиком с датой и основанием; отсутствие автоматических финансовых проводок.
- Исправление результата отдельной записью с причиной, сохранение прежних составов и подтверждения; повторная проверка приёмки после исправления.
- Защита устаревших форм и целиком отклоняемого группового назначения; подбор мастеров только в пределах доступа к объекту.
- Две бригады не могут установить одну физическую муфту на две работы одновременно. Одновременные повторы запроса не создают две записи. Одновременное подтверждение двумя руководителями не принимает устаревшую форму.
- Размеры файлов, лимит количества, приватная выдача, проверка SHA-256 и отказ при подмене сохранённых байтов.
- Предварительный просмотр XLSX без записи работ, поиск совпадений, защита повторного переноса, сохранение исходника и его доступность только руководителям.
- Объединённые строки нескольких дефектов, независимые боковые таблицы, перестановка столбцов, ведущие нули заводских номеров, шесть знаков километра, внешние формулы без исполнения и расхождение длины/состава.
- Исторические сведения о муфтах не становятся свободным запасом для мастера; их привязку к прежней работе проверяет руководитель.

Браузерные сценарии Chromium проходят на ширинах **1440, 768, 390 и 320 px**. Проверены сохранение текста и фотографии при отключённой сети, восстановление после перезагрузки при появлении сети, потеря ответа уже принявшего запись сервера и безопасный повтор без дубликата. Проверены внесение препятствия, результат одной конструкции для двух дефектов, отдельное подтверждение и приёмка, динамический выбор мастеров и групповое назначение. Ошибок JavaScript в сценариях нет.

Существующий браузерный сценарий документов проверяет 21 файл с двумя ошибочными вложениями, версии, просмотр, выдачу и немедленный отзыв доступа. Ожидание выбора получателя синхронизировано с DOMContentLoaded страницы настроек; проверки выдачи и отзыва сохранены.

## Контейнерное обновление с версии 5

На отдельных томах запущен прежний образ `interface-v5.0.0`. Созданы учебные пользователи с действующей сессией, объект, договор, человек, комплект, файл и финансовый начальный остаток. Образ заменён на `repairs-v6.0.0` без удаления этих томов.

Проверены сохранение сеанса входа и хеша пароля, версии сеанса, ключа приложения и адреса БД, SHA-256 файла, текущей версии, связей файла с объектом/договором/человеком, прежнего ограничения доступа работника и точных финансовых сумм. Семь страниц существующих и нового модулей возвращают 200 с новой версией в шапке.

На обновлённой установке внесён новый ремонт для двух дефектов с двумя физическими муфтами и вложением. Файл скачан и сверен; руководитель подтвердил выполнение. Приёмка и финансовые суммы автоматически не изменились. Временные сеансы проверки и конфигурационные значения в выпуск не включены.

Содержимое server и static итогового Docker-образа сверяется по SHA-256 с рабочими исходниками. Публичный HTML и сохранённый эталон не изменены. `manage.py check`, `makemigrations --check --dry-run`, синтаксическая проверка JavaScript и `git diff --check` выполняются без ошибок.

## Границы

Выпуск не заявляет готовыми распознавание фотографий ИИ, полный офлайн-реестр, офлайн-вход, фоновую синхронизацию, автоматические инженерные нормы или полный складской учёт движения материалов. Сохранение черновика требует поддерживаемого браузером IndexedDB; первоначальное открытие карточки требует связи.

Частные ведомости, исходное ТЗ, финансовые справки, аккаунты и служебные секреты в публичный выпуск не включены. Для испытаний используются синтетические книги и учебные записи. Проверка разбора предоставленного образца выполняется локально без публикации и без автоматического переноса его содержимого в рабочую базу.
