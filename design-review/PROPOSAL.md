# Макет 3: простая работа с объектом

Опора на подтверждённые требования: документы доступны автору и двум руководителям, дополнительные права выдаются отдельно; завершение ремонта подтверждают руководители; физический ремонт и принятие заказчиком различаются; координаты можно внести позже; одна конструкция может закрывать несколько дефектов.

Предложение интерфейса: главная руководителя с финансовой сводкой, объектами и новыми документами; из объекта открывается реестр дефектов, из строки — карточка. Короткая форма открывается только при добавлении/изменении данных. Настройки документов не занимают страницу просмотра файла. Договор автоматически подставляется при загрузке из его карточки.

Названия рабочих состояний, компоновка и оформление — предложение, не новые утверждённые правила компании. Данные учебные, без копирования частной справки, оригинальных договоров и персональных данных.

Проверено в Chromium: создание дефекта без GPS, проверка диапазона координат, результат ремонта для нескольких дефектов, различие вида мастера/руководителя, отсутствие автоматической приёмки заказчиком, обновление сводных количеств, поиск и фильтр. Повторно проверены сценарии документов из макета 2. Проверены ширины 390, 768 и 1440 px, ошибок JavaScript нет.

Это автономный HTML. Проверки не доказывают защищённость рабочего модуля: серверная авторизация и сохранение здесь отсутствуют. Установленная версия платформы 4.0 этим макетом не меняется.
