АРМАДА — МАКЕТ ИНТЕРФЕЙСА № 2

1. Распакуйте архив на компьютере.
2. Откройте index.html в браузере.
3. Нажмите «Договоры» слева, затем посмотрите документы договора ДЕМО-001.

Можно попробовать:
— добавить приложения из договора: привязка определяется автоматически;
— открыть договор и вернуться назад;
— развернуть комплект в списке документов;
— открыть доступ к одному файлу или целому комплекту;
— выбрать уже загруженный документ для связи с договором;
— добавить свой файл в окно загрузки. Файл никуда не отправляется;
— проверить пустой файл: ошибка одного файла не мешает остальным.

Это отдельный макет. Он не подключён к серверу, не сохраняет данные и не меняет платформу на Synology. Учебные документы не являются настоящими договорами. Вкладка «Финансы» показывает только предполагаемое расположение будущих показателей, без вымышленных сумм. Часть кнопок поясняет будущее действие уведомлением.

Это предложение для обсуждения, а не согласованный выпуск платформы.
Официальные справки Google Drive, Яндекс Диска, Dropbox и Битрикс24 оказались недоступны из текущей среды. Сравнение с их актуальными интерфейсами пока не подтверждено.
