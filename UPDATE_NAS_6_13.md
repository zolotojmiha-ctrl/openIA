# Обновление существующего NAS до 6.13

Сначала сохраните резервную копию базы, документов и конфигурации. Не удаляйте тома и не запускайте повторное создание руководителей: обновление использует существующие данные.

Архив содержит папку `openIA-feature-accounts-foundation`. Замените исходники существующего проекта `/volume1/docker/armada-test/openIA-feature-accounts-foundation`, сохранив приватные данные и локальную конфигурацию. Не копируйте чужую базу поверх своей.

В терминале NAS, из каталога проекта, после резервной копии:

```sh
sudo docker compose -p armada-test stop web mailworker
sudo docker compose -p armada-test build web
sudo docker compose -p armada-test up -d
sudo docker compose -p armada-test ps
sudo docker compose -p armada-test logs --tail=80 web mailworker
```

Если старая версия ещё не знает `mailworker`, остановите только `web` перед заменой файлов. Миграции выполняются при запуске web; инициализация добавит `mail-key`, сохранив остальные секреты. Сохраните новую копию конфигурации: без `mail-key` нельзя восстановить пароли подключённых ящиков.

У NAS остаётся прежний локальный адрес и проект `armada-test`. Не используйте `down -v`, `docker volume rm` и очистку базы. Для переноса на Beget следуйте отдельной инструкции; два одновременно доступных экземпляра с разными базами не являются синхронизацией.
