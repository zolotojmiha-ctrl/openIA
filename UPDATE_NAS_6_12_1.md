# Обновление 6.12.1 — пароль от 6 символов

Все функции 6.12.0 сохранены. Исправлен минимум пароля при создании двух руководителей и смене пароля: 6 символов вместо 14. Временные пароли при создании сотрудника, создании его аккаунта из персонала и сбросе пароля теперь также состоят из 6 символов. Прежние пароли продолжают работать. Защита от перебора, проверка распространённых/полностью цифровых паролей и обязательная первая смена сохранены.

Папка архива: **openIA-feature-accounts-foundation**.
Путь: **/volume1/docker/armada-test/openIA-feature-accounts-foundation**.
Проект: **armada-test**.

1. Остановите существующий проект armada-test в Container Manager. Если окно DSM снова зависнет, используйте уже подключённый терминал Mac:

```sh
sudo docker stop --time 30 armada-test-web-1 armada-test-init-1 armada-test-db-1
```

2. Замените исходники в указанной папке содержимым новой папки из архива. В конфигурации YAML проекта должны быть новые образы для web и init: **armada-test-web:passwords-v6.12.1** и секции build из нового docker-compose.yml. Прежние тома config, documents, database и настройки адреса сохраняются.
3. Пересоздайте/соберите проект в Container Manager с обновлённой конфигурацией. В этой версии DSM соответствующее действие называется «Создать». Не используйте только «Пуск» старых контейнеров: это не обновит код внутри них. Не удаляйте тома и данные.
4. После запуска выполните в подключённом к NAS терминале:

```sh
sudo docker exec -it armada-test-web-1 python server/manage.py bootstrap_leaders
```

Команда нужна только если руководители ещё не созданы. Для каждого введите ФИО, телефон, пароль от 6 символов и повтор пароля. Скрытый ввод не показывает символы. Если учётные записи уже созданы, повторно их создавать не нужно.

Вход: http://192.168.50.248:18080/cabinet/login/ . Версия в шапке после входа: **6.12.1-passwords**.

Архив не содержит пользовательских записей, финансовых показателей, документов и секретов. Ограничения функциональности 6.12.0 перечислены в FEEDBACK_6_12.md и остаются прежними. Обновление NAS разработчиком не выполнялось.
