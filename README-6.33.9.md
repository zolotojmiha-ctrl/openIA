# 6.33.9 — ведомость ПТО, отчёты по дефектам и резервные копии

- В «Ведомости выполнения» появилась кнопка «Скачать для ПТО». Excel включает координаты, фактический метод ремонта, размеры и заводские номера установленных муфт. Выгрузка учитывает фильтры и права доступа. Порядок «Км → № дефекта → № секции» совпадает в таблицах и выгрузках дефектов. Прежние шаблоны реестра загружаются по заголовкам, файлы скачиваются с именами «armada-» и названием отчёта.
- В отчёт о ремонте добавлены размеры шлифовки, отметки об обустройстве переезда через нефтепровод и установке шпунтов. Фотографии открываются внутри карточки с переходом между снимками.
- Уточнение конструкции принимает ввод длины и толщины стенки в целых миллиметрах. При подборе муфт показываются работы с действующими дефектами.
- Для копий на Яндекс Диске действует срок хранения. Очистка выполняется после успешной проверки новой копии и учитывает состояние предыдущих копий.
- Поддерживается переход с 6.33.8 и повторный запуск. Миграция добавляет поля состояния резервных копий. Установщик создаёт зашифрованную копию и сохраняет настройки.

Каталог recovery содержит прежнюю версию приложения и закрытые настройки. Сохраняйте последний завершённый комплект и незавершённые комплекты. Старые завершённые комплекты можно удалить вручную после проверки восстановления соответствующей копии. Для просмотра списка используйте `python3 deploy/beget/recovery_inventory.py --directory /opt`.
