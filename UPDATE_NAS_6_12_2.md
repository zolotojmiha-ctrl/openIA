# Обновление 6.12.2 — простые пароли

Разрешены любые пароли длиной от 6 символов, включая 123456, полностью цифровые, распространённые и совпадающие с именем. Проверки сложности удалены. Два руководителя могут использовать одинаковый пароль, но телефоны должны быть разными. Автоматические временные пароли при создании и сбросе доступа состоят из 6 цифр. При обязательной первой смене можно выбрать простой пароль; он должен отличаться от текущего.

На показанной ошибке bootstrap_leaders учётные записи не были сохранены: команда сохраняет обоих руководителей только после успешного ввода всех данных. Повторно очищать базу не нужно.

Папка: **openIA-feature-accounts-foundation**.
NAS: **/volume1/docker/armada-test/openIA-feature-accounts-foundation**.
Проект: **armada-test**.

1. Остановите проект в Container Manager. При зависшем окне остановки в подключённом к NAS терминале Mac выполните:

```sh
sudo docker stop --time 30 armada-test-web-1 armada-test-init-1 armada-test-db-1
```

2. Замените исходники в папке проекта содержимым архива. Обновите сохранённый YAML проекта из нового docker-compose.yml, сохранив настройки NAS и подключение существующих томов. Образы web/init должны быть **armada-test-web:simple-passwords-v6.12.2**, с секциями build.
3. Пересоберите/пересоздайте существующий проект armada-test через «Действие → Создать». Только «Пуск» старых контейнеров не обновляет код. Тома config/database/documents не удаляйте.
4. После успешного запуска повторите настройку руководителей:

```sh
sudo docker exec -it armada-test-web-1 python server/manage.py bootstrap_leaders
```

Порядок: ФИО → телефон → пароль → повтор пароля, затем второй руководитель. Ввод скрытый. Если руководители уже существуют, повторная настройка не нужна; их пароли не меняются этим обновлением.

Вход: http://192.168.50.248:18080/cabinet/login/ . Версия в шапке: **6.12.2-simple-passwords**.

Включён код 6.12.1 и предыдущих выпусков. Существующие данные и пароли сохраняются. Учебных данных в архиве нет. Остальные ограничения функциональности из FEEDBACK_6_12.md не изменены. NAS разработчиком не обновлялся.
