Файлы ZIP сверяются с неизменяемым Git-коммитом; образ собирается из этого ZIP. Итоговый внешний VALIDATION.md, подписанный JSON и SOURCE_FILES.json рядом с пакетом содержат хэши, image ID и окончательную сверку. Ключ подписи создан по прямому поручению владельца отдельно от репозитория. Подпись окончательного комплекта выполняется после записи этого протокола; временный ключ тестового установщика не является ключом выпуска.

Зашифрованная копия действительно восстановлена в отдельную PostgreSQL 17 с распаковкой файлов и сверкой строк/хэшей. Проверка неверного количества строк отказала без выдачи успешного receipt. Во время штатной копии/переключения/миграций попытки записи блокировались. На старых версиях 6.25–6.29 тестовый адаптер предъявлял Compose без maxworker, чтобы проверить обнаруженную совместимость. После начала миграций проверены остановка писателей и ручное восстановление, автоматического отката БД нет.

Границы: полный прогон использовал отдельный временный нативный PG17.11 из закреплённого официального образа, localhost и fsync=off только на синтетических данных. Матрица обновлений использовала тот же движок/штатный entrypoint в минимальном контейнере с библиотеками/локалью хоста, а не точный rootfs провайдера. Proxy/mailworker заменены локальными заглушками; настоящий MAX-worker работал без доставки. Настоящие SMTP/MAX/Яндекс, публичный TLS, рабочий VPS и Figma не проверялись. MAX выключен по умолчанию; нужен отдельный пилот. Расписание доверенного восстановления и внешняя копия не включены. Старые 6.29.0/6.30.0 не переписаны; публикации/установки 6.31.0 пока не было.

Ограниченная CSP не является строгой nonce/script-src политикой. Исторические пути deploy/synology сохранены для совместимости. Base Python/PG закреплены digest; локальный armada-db:17 не имеет registry digest, для точного закрепления предусмотрен ARMADA_DATABASE_IMAGE. Перед настоящим обновлением обязательны проверка восстановленного сервера/версии/данных, независимое получение публичного ключа и сохранение закрытого ключа у владельца вне VPS/Git.

Выполнено в разработке: 5 проверок заморозки, 9 сценариев фаз/дерева, 32 профильных SQLite-теста резервирования, 7 проверок политики/шифрования, действительное восстановление синтетического зашифрованного архива в отдельный PostgreSQL 17 с проверкой строк/файлов и отказом при несовпадении, 14 сценариев подписанного установщика, два теста CSP, синтаксис Compose при штатных/тестовых доменах и Caddy validate без сети. Конечный расширенный набор и общий прогон ещё выполняются.

Ключ подписи создан по прямому поручению владельца, вне Git/артефакта, закрытый файл 0600. В тестах используются отдельные временные ключи. Рабочий ключ восстановления не получен/не используется. Закрытую часть подписи надо сохранить владельцу отдельно на Mac; публичную часть распространять независимым доверенным способом. Облако не является единственным долговечным хранилищем ключа.

Итоговый протокол должен включать исходный коммит, результат полного PostgreSQL/Chromium, SHA256 ZIP/установщика, image ID/файлы, все проверенные исходные версии, принудительные сбои и контрольные суммы восстановления; границы стенда, непроверенные реальные API и отсутствие установки на VPS. Подпись окончательных метаданных выполняется после фиксации результатов, а не до неё.
