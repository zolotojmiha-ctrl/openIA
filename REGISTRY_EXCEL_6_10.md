# Excel объектов, контрактов и персонала — 6.10.0-registry-excel

В разделы «Объекты», «Договоры» и «Персонал» добавлены заметные кнопки выгрузки, загрузки и скачивания шаблона. Существующие Excel-разделы бригад, техники, складов, субподрядчиков, дефектов и сроков документов сохранены.

Для редактирования скачайте реестр, измените значения и загрузите обратно. ID и версия существующих записей должны оставаться прежними. Для новой записи оставьте ID и версию пустыми. Совпадение названия или ФИО не используется для автоматической замены. Строка без ID создаёт новую запись: для повторного редактирования сначала выгрузите её созданный ID. Удаление строк из файла не удаляет записи. Повторное применение одного подтверждённого предварительного просмотра не создаёт дублей.

Сначала показывается предварительный просмотр с действием «Создать»/«Обновить». До подтверждения данные и история не меняются. При применении снова проверяются права, видимость и версия каждой записи. Ошибка отменяет весь перенос. За один файл — до 500 строк; если большой объём примечаний превышает размер подписанного просмотра, программа предлагает разделить файл. Формулы не принимаются, выгрузка создаёт текстовые ячейки, а не исполняемые формулы.

Объекты: название, вид, местоположение, состояние, даты начала и окончания. Контракты: доступные реквизиты, несколько видов работ, несколько связанных объектов, состояние; у руководителей также сумма и внутренние примечания. Персонал: ФИО и должность карточки. Даты принимаются в формате ГГГГ-ММ-ДД, ДД.ММ.ГГГГ и как даты Excel с учётом системы 1900/1904. Состояния и виды работ выгружаются русскими названиями; программные ключи также принимаются при импорте.

Для связей контрактов перечислите ID объектов через точку с запятой. Сначала загрузите объекты, затем выгрузите их ID и заполните контракты. Один контракт может охватывать несколько объектов. Существующие назначения бригад, техники, поручения субподрядчикам и ремонты не позволяют убрать использованные связи или вид работ через Excel.

Доступ для объектов и контрактов — существующее право projects.manage, для персонала — personnel.manage. Должность сама по себе его не выдаёт. Делегат видит только свои объекты/контракты; закрытые реквизиты выгружаются пустыми и при обратной загрузке сохраняются. Для изменения контракта нужен доступ ко всем его объектам. Новый объект и контракт становятся доступны создавшему их делегату по тем же правилам, что при ручном создании. Права коллег не выдаются автоматически.

Учётные записи, роли ЛК, пароли, выдача прав и связывание сотрудника с учётной записью остаются явными действиями в существующих формах. Изменение должности в персонале не меняет роль ЛК. Архивный признак персонала справочный; архивирование/восстановление выполняется в карточке. Архив контрактов доступен для выгрузки, а изменение закрытого контракта заблокировано. Процедура закрытия и восстановления сохраняется.

Выгружается доступный реестр независимо от поиска на странице. Для персонала и контрактов вкладка «Архив» переключает архивную выгрузку; объекты выгружаются во всех состояниях. Архивный контракт не предназначен для обратного редактирования до восстановления. Миграция projects/0010 создаёт только квитанции импорта; существующие данные не переписывает. Журнал содержит прежние и новые значения обновлённых карточек.

NAS не обновлялся. Этот выпуск объединяет код предыдущих этапов; самостоятельная установка выполняется через Container Manager по UPDATE_NAS_6_10.md.
